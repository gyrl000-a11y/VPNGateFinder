# 드랍필 (DropFill)

Supreme KR · Palace KR 모바일 사이트용 개인 앱.
장바구니에 담으면 체크아웃까지 자동으로 넘어가고, 연락처·배송지·카드 정보를 채워 둡니다.
**최종 결제 버튼은 누르지 않고 빨간 테두리로 표시만 합니다.**

## 빌드 (Mac 없이)

VPNGateFinder 저장소의 `dropfill` 브랜치에 있습니다 (main과 분리).

1. `dropfill` 브랜치에 푸시하면 Actions가 실행됩니다: 스크립트 테스트 → 시뮬레이터 테스트(실제 WebKit) → 기기용 빌드.
2. 끝나면 Releases의 `dropfill-latest`에 `DropFill.ipa`가 올라갑니다 (VPN 앱의 `latest`와 별개).
3. 테스트 로그·실행 화면은 `dropfill-test-results` 브랜치에 저장됩니다.
4. Sideloadly / LiveContainer로 설치합니다.

## 사용

1. **설정** 탭에서 연락처·배송지·카드를 입력합니다. 카드는 기기 키체인에만 저장됩니다.
2. Supreme / Palace 탭에서 로그인한 뒤 상품을 담습니다.
3. 담기 성공이 감지되면 체크아웃으로 이동 → 자동입력 → 결제 버튼에 빨간 테두리.
4. 확인 후 결제 버튼만 직접 누릅니다.

하단 버튼: 뒤로 · 앞으로 · 새로고침 · 홈 · 장바구니 · ⚡자동진행 켜기/끄기 · 🪄다시 채우기

## 대기열·캡차

우회하지 않고, 직접 기다리고 푸는 시간을 줄이는 기능만 있습니다.

- 대기열(Shopify 대기열, queue-it 등)이나 캡차(hCaptcha, reCAPTCHA, Cloudflare)가 뜨면 진동과 알림을 보내고, 위쪽에 주황/빨강 띠를 띄웁니다.
- 대기 중에는 화면이 꺼지지 않습니다. 다른 탭에 있으면 탭에 `!` 표시가 붙습니다.
- 대기열을 통과하면 "통과" 알림을 보내고 그 탭으로 바로 전환합니다. 대기·캡차 중에는 자동 이동을 멈췄다가 통과 후 다시 동작합니다.
- 페이지에 대기 순번·예상 시간이 보이면 띠에 같이 표시합니다.
- 대기 중 뒤로·새로고침·홈·장바구니를 누르면 "순번을 잃을 수 있어요" 확인창을 띄우고, 밀어서 뒤로 가기도 막습니다.
- 메모리 부족으로 웹 화면이 죽으면 같은 주소로 자동 복구합니다. 대기 중엔 20초마다 쿠키를 저장합니다.
- (선택) 대기 중 백그라운드 유지: 대기열·캡차 화면일 때만 무음 오디오로 앱을 깨워 둡니다.
- 드랍 시간 알림: 요일·시간을 정해 두면 매주 5분 전, 1분 전에 알려 줍니다.
- 로그인·대기 순번 같은 세션 쿠키를 키체인에 저장해 두고, 앱을 다시 열면 쿠키를 되살린 뒤 마지막 페이지에서 시작합니다.
- 백그라운드 유지를 끈 상태라면 iOS가 앱을 30초쯤 뒤에 멈춥니다. 대기열에서는 앱을 앞에 켜 두는 게 가장 확실합니다.

## 동작 방식

| 파일 | 역할 |
|---|---|
| `js/hook.js` | 페이지 쪽에서 `/cart/add`, GraphQL `cartLinesAdd` 성공 응답을 감지해 앱에 알림 (개인정보 없음) |
| `js/gate.js` | 대기열·캡차 화면과 대기 순번을 감지해 앱에 알림만 보냄 |
| `DropFillTests/` | 시뮬레이터의 실제 WebKit에서 자동입력·결제 버튼 미클릭·대기열 감지 검증 |
| `js/autofill.js` | 격리된 스크립트 영역에서 실행. 쇼핑몰 도메인에는 주소, 결제 입력 도메인(Shopify 카드칸 등)에는 카드만 받아서 채움 |
| `DropFill/Scripts.swift` | 위 두 JS를 묶은 자동 생성 파일 — JS를 고치면 `./gen_scripts.sh` 실행 |

- 칸 인식 순서: `autocomplete` 속성 → `name`/`id` → 라벨 문구(한국어/영어)
- 사용자가 직접 고친 칸은 다시 덮어쓰지 않음
- 할인코드·기프트카드·검색칸은 건드리지 않음
- 카드사 앱카드/ISP 같은 외부 앱 호출과 결제 팝업창을 처리

## 한계

- 처음 드랍 전에 일반 상품으로 체크아웃 화면까지 한 번 테스트해 보세요. 사이트 구조가 바뀌면 칸 인식 규칙을 고쳐야 할 수 있습니다.
- 결제가 국내 PG(이니시스·토스 등) 창이면 카드사 앱 인증 단계가 있어서 카드번호 자동입력은 해당되지 않습니다. 다른 결제 도메인이면 설정 → 사이트에 도메인을 추가하세요.
- 캡차, 대기열, 재고 새로고침 같은 사이트 보호 장치를 우회하는 기능은 없습니다.
- Apple Pay는 사이드로드 앱의 웹뷰에서 동작하지 않습니다.
