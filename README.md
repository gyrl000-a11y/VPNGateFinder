# VPN 찾기 (VPNGateFinder)

VPN Gate(일본 쓰쿠바 대학) 공개 서버 목록과, 직접 가져온 OpenVPN 설정 파일들을 한데 모아 내 폰 기준으로 가장 빨리 응답하는 서버를 자동으로 골라 주는 iOS 앱입니다. 고른 서버의 설정 파일(.ovpn)을 OpenVPN Connect 앱으로 넘겨서 연결합니다.

## 앱이 하는 일

1. 앱을 열면 VPN Gate 서버 목록을 바로 받아요. 마지막으로 받은 목록은 저장해 둬서, 새 목록을 받는 동안이나 못 받는 날에도 바로 보입니다.
2. 고른 국가의 점수 상위 10개 서버와 "내 설정 파일"에 넣어 둔 서버들에 OpenVPN 첫 인사 패킷을 보내서, 서버가 실제로 대답하는지와 걸린 시간을 확인해요. TCP·UDP 둘 다 됩니다.
3. 직접 대답한 서버(✅ 표시)를 먼저, 그중 빠른 순으로 골라 위에 보여 주고, **OpenVPN으로 보내기** 버튼으로 설정 파일을 넘깁니다.
4. 연결해 봤는데 안 되면 **연결이 안 돼요**를 누르세요. 그 서버는 24시간 동안 자동 선택에서 빠지고 바로 다음 서버를 골라 줍니다. 그냥 다른 걸 써 보고 싶으면 **다른 서버로 바꾸기**.
5. **연결 확인**에서 지금 바깥에 보이는 내 IP와 나라를 볼 수 있어요. OpenVPN에서 연결하고 앱으로 돌아오면 자동으로 다시 확인하고, VPN Gate 서버 IP와 같으면 "VPN 연결됨"이라고 알려 줍니다. (확인할 때 ipinfo.io에 접속합니다)
6. 연결이 확인된 서버(⭐)는 7일 동안 기억해 둡니다. 다음에 자동 선택할 때 점수 순위와 상관없이 후보에 넣고, 대답만 하면 먼저 골라 줘요. 한 번 잘 된 서버는 또 잘 될 가능성이 높거든요.
7. **다운로드 속도 재기**로 연결된 상태의 실제 속도를 볼 수 있어요. 최대 7초, 데이터는 최대 25MB를 씁니다.
8. VPN이 켜진 상태에서 서버를 고르면 측정값이 VPN을 거친 값이라 부정확해서, 그럴 땐 화면에 알려 줍니다.
9. VPN Gate 목록은 점수순·속도순·응답순으로 정렬할 수 있고, **목록 전체 응답 확인**으로 보이는 서버를 한꺼번에(최대 80개) 확인할 수 있어요.
10. 서버를 길게 누르면 "이 서버로 정하기", "응답 다시 확인", "24시간 제외" 메뉴가 나옵니다.
11. 국가, "TCP 서버만", "내 파일도 같이 비교", 정렬 설정은 저장돼서 다음에 열 때도 그대로예요.

---

## 준비물

- Windows PC (아이폰 연결용 USB 케이블)
- GitHub 계정 (무료)
- Apple ID (무료, 평소 쓰는 계정이나 부계정)
- 아이폰에 **OpenVPN Connect** 앱 (App Store 무료)

---

## 1단계: GitHub에서 앱 파일(IPA) 만들기

Mac 대신 GitHub가 제공하는 클라우드 Mac이 빌드를 해 줍니다.

1. github.com 로그인 → 오른쪽 위 **+** → **New repository**
   - 이름: `VPNGateFinder`
   - **Public**으로 만들면 빌드 시간 제한 없이 무료입니다. (Private도 월 무료 시간 안에서 충분히 돼요)
   - "Add a README file"은 체크하지 않음 → **Create repository**
2. 만들어진 저장소 화면에서 **uploading an existing file** 링크 클릭
3. 압축을 푼 폴더 안의 `project.yml`, `README.md`, `Sources` 폴더를 끌어다 놓고 **Commit changes**
4. 빌드 설정 파일은 숨김 폴더라 끌어다 놓기로 안 올라갈 수 있어서 직접 만듭니다.
   - **Add file → Create new file**
   - 파일 이름 칸에 정확히 `.github/workflows/build.yml` 입력 (슬래시를 치면 폴더가 자동으로 생겨요)
   - 내용 칸에 압축 파일 안 `.github/workflows/build.yml` 내용을 메모장으로 열어 복사·붙여넣기
   - **Commit changes**
5. 위쪽 **Actions** 탭 → 왼쪽 **Build IPA** → 이미 돌고 있으면 기다리고, 없으면 **Run workflow** 클릭
6. 5~10분 뒤 초록색 체크가 뜨면 그 실행을 눌러 맨 아래 **Artifacts**의 `VPNGateFinder-ipa`를 다운로드
7. 받은 zip을 풀면 `VPNGateFinder.ipa`가 나옵니다.

빨간 X가 뜨면 실행을 눌러 **Show errors only** 단계를 펼쳐서, 거기 나온 오류 줄을 복사해 저한테 보내 주세요. 전체 기록은 Artifacts의 `build-log`로도 받을 수 있어요.

## 2단계: Sideloadly로 아이폰에 설치

1. PC에 **Sideloadly** 설치 (sideloadly.io)
   - Windows는 Microsoft Store 버전이 아닌 Apple 홈페이지에서 받은 **iTunes**와 **iCloud**가 필요합니다. Sideloadly 설치 화면에서 링크를 안내해 줘요.
2. 아이폰을 USB로 연결하고, 아이폰에 "이 컴퓨터를 신뢰" 뜨면 **신뢰**
3. Sideloadly에 `VPNGateFinder.ipa`를 끌어다 놓고, Apple ID 입력 → **Start**
4. 처음이면 Apple ID 비밀번호와 2단계 인증 코드를 물어봐요.

### 아이폰에서 허용하기 (처음 한 번)

- **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜기 → 재시동 → 켜기 확인 (이 메뉴는 Sideloadly로 앱을 한 번 설치한 뒤에 나타나요)
- **설정 → 일반 → VPN 및 기기 관리** → 내 Apple ID 이메일 → **신뢰**

---

## 3단계: 사용법

1. **VPN 찾기** 앱 열기 → 잠시 기다리면 "자동 선택"에 서버가 뜸
2. **OpenVPN으로 보내기** → 공유 화면에서 **OpenVPN** 선택
   - 목록에 없으면 공유 화면 앱 줄을 옆으로 넘겨 **더 보기**에서 찾기
3. OpenVPN Connect에서 **ADD** → 처음이면 VPN 구성 추가 허용 → 스위치를 켜서 연결
4. 연결이 안 되면 앱으로 돌아와 **연결이 안 돼요** → 새로 고른 서버를 다시 보내기
5. 앱의 **연결 확인**에 나라가 바뀌어 보이면 성공

OpenVPN Connect에 쌓인 예전 프로필은 왼쪽으로 밀어서 지우면 됩니다.

## 다른 곳의 서버 추가하기 (내 설정 파일)

VPN Gate 말고도 OpenVPN 설정 파일(.ovpn)을 주는 곳이라면 어디든 넣을 수 있어요.

1. 사파리에서 .ovpn 파일을 다운로드 → 파일 앱의 "다운로드" 폴더에 저장됨
   - zip으로 받았다면 파일 앱에서 zip을 한 번 탭하면 폴더로 풀립니다.
2. 앱의 **내 설정 파일 → 설정 파일(.ovpn) 가져오기** → 파일 여러 개를 한 번에 골라도 돼요.
3. 이후 자동 선택 때 VPN Gate 서버와 함께 응답 속도를 재서 비교합니다.
   - 국가 메뉴에서 **📁 내 파일만**을 고르면 가져온 파일들 안에서만 골라요.

표시 아이콘

- 🔑 열쇠: 연결할 때 아이디·비밀번호가 필요한 서버. 파일을 받은 사이트에 안내된 값을 OpenVPN Connect에서 입력하고 저장해 두면 됩니다.
- ⚠️ 경고: 인증서가 .ovpn 안에 들어 있지 않고 별도 파일(ca.crt 등)로 되어 있는 경우. OpenVPN Connect에서 그대로는 연결이 안 될 수 있어요. 인증서가 안에 포함된 버전의 파일을 받으세요.

넣을 만한 곳

- **VPNBook**: 무료지만 서버가 적고 느린 편이며, 모든 사용자가 같은 아이디·비밀번호를 씁니다. 비밀번호가 주기적으로 바뀔 수 있어요.
- **Proton VPN 무료 계정**: 계정 설정에서 OpenVPN 설정 파일을 받을 수 있다면 넣어 두세요. 이때 아이디·비밀번호는 로그인 정보가 아니라 계정 페이지에 따로 나오는 "OpenVPN 사용자 이름/비밀번호"입니다.
- 출처를 알 수 없는 사이트나 게시판의 파일은 넣지 않는 게 좋아요. 누가 운영하는 서버인지 모르면 트래픽이 어디로 가는지도 알 수 없습니다.

## 7일마다 다시 설치

무료 Apple ID로 설치한 앱은 7일이 지나면 열리지 않아요. 그때 PC에서 Sideloadly로 같은 IPA를 다시 **Start** 하면 됩니다. 앱을 지우지 않고 덮어써서 설정은 남아요.

- Sideloadly 설정에서 **자동 갱신(Auto refresh)**을 켜 두면 PC와 아이폰이 같은 와이파이에 있을 때 알아서 다시 서명해 줍니다.
- 무료 Apple ID는 이렇게 설치한 앱을 동시에 3개까지만 쓸 수 있어요.

## 연결이 안 될 때

- **"응답 없음"이 많다**: 공개 서버는 자주 꺼졌다 켜집니다. 오른쪽 위 새로고침으로 목록을 다시 받아 보세요.
- **✅ 표시 없이 시간만 나온다**: 포트는 열려 있는데 OpenVPN 대답은 확인하지 못한 서버예요. 추가 보안 설정(tls-auth)이 걸린 파일이면 원래 이렇게 나오고, 연결은 될 수 있습니다.
- **제외한 서버를 되돌리고 싶다**: 설정 칸의 **제외한 서버 다시 넣기**를 누르거나, 서버 상세 화면에서 "자동 선택에서 제외"를 끄면 돼요.
- **OpenVPN에서 cipher/암호화 관련 오류**: 서버마다 오래된 설정을 쓰는 경우가 있어요. 다른 서버를 고르면 대부분 해결됩니다.
- **회사·공용 와이파이에서 안 됨**: 네트워크가 VPN을 막는 경우가 있어요. LTE/5G로 바꿔서 시도해 보세요.
- **TCP 서버만 끄기**: UDP 서버까지 후보에 넣어요. UDP가 더 빠를 때가 많지만 회사·학교 와이파이에서는 막히기도 합니다.

## 주의

VPN Gate는 자원봉사자가 운영하는 공개 서버라 운영자가 트래픽을 볼 수 있습니다. 은행·쇼핑몰 로그인이나 결제는 VPN을 끄고 하세요. VPN Gate 쪽도 접속 기록을 일정 기간 보관한다고 밝히고 있어요.
